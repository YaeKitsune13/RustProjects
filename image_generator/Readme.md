# 🦀 AI Studio Orchestrator & VRAM Monitor (`image_generator_viewer`)

Единый высокопроизводительный контроллер, мониторинг ресурсов видеокарты и оркестратор пайплайнов генерации изображений (**ComfyUI**) и локальных языковых моделей (**Ollama / llama.cpp**), написанный на **Rust**.

Проект создан для замены связки разрозненных сервисов на единый нативный бэкенд с минимальным потреблением памяти и жестким контролем над **VRAM**, чтобы избежать ошибок `CUDA Out of Memory` при совместной работе LLM и диффузионных моделей на одной видеокарте.

---

## ⚡ Ключевые возможности

- **📊 Мониторинг GPU в реальном времени (Zero-Overhead):** Прямое чтение показателей видеокарты через нативный драйвер NVIDIA (`NVML`) без парсинга консольных утилит: потребление VRAM (МБ/%), температура ядра, загрузка GPU и энергопотребление (W).
- **🧠 Умный менеджмент VRAM (LLM + Diffusion):** Автоматическая оркестрация очереди — генерация/улучшение промпта через локальную LLM, принудительная выгрузка языковой модели из видеопамяти (`keep_alive: 0` / drop контекста), проверка освобождения VRAM и последующий запуск рендера в ComfyUI.
- **🚀 Встроенный Лаунчер процессов:** Асинхронный запуск, перезапуск и аварийная остановка (`kill`) дочернего процесса ComfyUI с перехватом `stdout`/`stderr` логов в реальном времени и поддержкой профилей аргументов (`--lowvram`, `--medvram`, `--listen`).
- **🔌 Полная интеграция с ComfyUI API:** Модификация JSON-воркфлоу на лету (подстановка промптов, сидов, чекпоинтов, LoRA и параметров KSampler / FaceDetailer / апскейлеров) и отслеживание прогресса генерации по WebSocket.
- **🖥️ Мультиплатформенный интерфейс:**
  - **TUI-режим** (`ratatui`) — легковесный терминальный дашборд.
  - **Web / Desktop GUI** (`Axum` + `Tauri` + `Vue 3`) — полноценный графический клиент.

## 🛠️ Технологический стек

### Backend & Core (Rust)

- **Асинхронный рантайм и сеть:** `tokio`, `axum` (REST & WebSocket API), `reqwest`, `tokio-tungstenite`
- **Аппаратный мониторинг:** `nvml-wrapper` (NVIDIA Management Library), `sysinfo` (CPU/RAM)
- **База данных и сериализация:** `sqlx` (SQLite с проверкой запросов на этапе компиляции), `serde`, `serde_json`
- **Работа с LLM:** `ollama-rs` / `llama-cpp-2`
- **Терминальный интерфейс (TUI):** `ratatui`, `crossterm`
- **Утилиты и логирование:** `anyhow`, `tracing`, `uuid`, `dotenvy`, `chrono`

### Frontend (Web & Desktop)

- **Фреймворк:** `Vue 3` (Composition API) + `TypeScript` + `Pinia`
- **Десктопная оболочка:** `Tauri v2`

## 🏗️ Архитектура проекта

Проект спроектирован с разделением бизнес-логики и представления для плавной миграции между CLI/TUI, Web API и Tauri:

```text
image_generator_viewer/
├── Cargo.toml
├── .env.example
└── src/
    ├── main.rs            # Точка входа, инициализация рантайма и логгера
    ├── config.rs          # Чтение .env и конфигураций запуска
    ├── state.rs           # Глобальное состояние приложения (Arc<Mutex<AppState>>)
    ├── hardware/
    │   ├── mod.rs
    │   └── gpu.rs         # Опрос видеокарты через nvml-wrapper и sysinfo
    ├── services/
    │   ├── mod.rs
    │   ├── comfy.rs       # HTTP/WS клиент для ComfyUI + мутация JSON-воркфлоу
    │   ├── llm.rs         # Генерация промптов через Ollama / llama.cpp и сброс VRAM
    │   └── launcher.rs    # Управление системным процессом генератора (tokio::process)
    ├── db/
    │   └── mod.rs         # SQLite: история генераций, пути к файлам и пресеты (sqlx)
    ├── api/
    │   ├── mod.rs
    │   ├── routes.rs      # Роуты Axum для фронтенда на Vue 3
    │   └── ws.rs          # WebSocket-стриминг статистики VRAM и прогресса рендера
    └── tui/
        └── mod.rs         # Терминальный интерфейс на ratatui
```

## 🚀 Быстрый старт и установка

### Требования

- Установленный тулчейн **Rust** (`rustup`, `cargo` >= 1.80)
- Видеокарта NVIDIA с установленным проприетарным драйвером (`libnvidia-ml.so` в Linux / `nvml.dll` в Windows)
- Установленный **ComfyUI** (для пайплайна генерации) и **Ollama** (опционально)

### Настройка окружения

Создайте файл `.env` в корне проекта:

```env
SERVER_PORT=8080
DATABASE_URL=sqlite://studio.db

# Пути и адреса внешних сервисов
COMFY_API_URL=[http://127.0.0.1:8188](http://127.0.0.1:8188)
COMFY_WS_URL=ws://127.0.0.1:8188/ws
COMFY_EXEC_PATH=/path/to/ComfyUI/main.py
OLLAMA_API_URL=[http://127.0.0.1:11434](http://127.0.0.1:11434)
DEFAULT_LLM_MODEL=qwen2.5-coder:7b
```

### Сборка и запуск

```bash
# Запуск в режиме разработки
cargo run

# Сборка оптимизированного релизного бинарника
cargo build --release
```
